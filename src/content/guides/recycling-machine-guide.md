Save Broken CDs and Broken Glasses when you need Refined Quartz: each gives one piece in a Recycling Machine. Newspaper, Driftwood, and Trash have less predictable results. Sort them separately if you are trying to finish a particular recipe.

> **At a glance**
>
> - The recipe unlocks at **Fishing level 4**.
> - Crafting requires **25 Wood, 25 Stone, and 1 Iron Bar**.
> - Broken CDs and Broken Glasses each become **1 Refined Quartz**.
> - Soggy Newspaper can produce Cloth, but that outcome is not guaranteed.
> - Joja Cola is not a valid recycling input.

## Start with the output that solves your shortage

The [Recycling Machine reference](https://wiki.stardewvalley.net/Recycling_Machine) lists the input rules. Choose a material target before loading a long queue. If your next project is short of Refined Quartz, glasses and CDs deserve priority over a mixed pile of low-value inputs.

This creates a useful connection between fishing and farm upgrades. A few overlooked catches may supply part of a crafting plan without another mining trip. Our [sprinkler guide](/guides/sprinkler-guide/) and [lightning rod guide](/guides/lightning-rods-battery-packs-guide/) show projects where that reserve can matter.

Keep the target modest. Finishing the materials for one planned batch is easier to evaluate than trying to turn an entire backlog into an unspecified future stockpile.

## Sort by certainty, not by how dirty the item looks

Several unwanted-looking items have different rules:

| Input | Useful planning interpretation |
|---|---|
| Broken CD | Predictable Refined Quartz |
| Broken Glasses | Predictable Refined Quartz |
| Soggy Newspaper | Usually Torches; Cloth is a possible alternative |
| Driftwood | Wood or Coal |
| Trash | One of several basic resource outcomes |
| Joja Cola | Not accepted by the machine |

The distinctions matter when a recipe has a deadline. If you need Cloth, a pile of newspapers offers attempts rather than certainty. Do not commit to a time-sensitive task that depends on a lucky result arriving from the next piece.

A deterministic input can support a firm material count. A random input should be treated as supplemental supply until the output is actually in your inventory.

## Put the machine where you spend time

Processing takes **one in-game hour** per item, according to the reference. You do not need to stand beside it. Load an input before another farm task, then collect when you naturally pass again.

A machine beside a regularly used storage chest can be more productive in practice than one placed in a remote “perfect” workshop. You are more likely to notice the output and refill it without making a separate trip.

If you use [Crab Pots](/guides/crab-pot-route-guide/), keep their recyclable catches together. Bring that stack back at the end of the route rather than interrupting each pot interaction to manage it individually.

## Add machines only when the queue is real

One machine is enough to learn the routine. If it repeatedly finishes while you are elsewhere and a backlog keeps growing, another machine may fit. If you often forget the first machine, copying it does not solve the attention problem.

Use a sample week to observe the input supply. A rod-fishing session can produce an irregular pile, while a daily pot route creates a more regular collection chore. Your recycling capacity should match the supply you actually create, not a hypothetical full-time fishing schedule.

Avoid spending the last iron bar on a machine that will mostly sit empty. It may be more useful in the main equipment project the recycling was supposed to support.

## Decide what “enough” looks like

For example, if a project needs four Refined Quartz and you have four Broken CDs, those inputs meet that component exactly. That does not mean the rest of the project is ready; confirm all other materials before announcing the shortage solved.

After the reserve is complete, decide whether to continue, store a small surplus, or stop collecting a particular input.

Our [storage guide](/guides/backpack-storage-guide/) explains a useful separation: project materials, ordinary processing inputs, and items you plan to sell should not all occupy the same mental category.

## When to move on

Recycling is doing its job when it supplies useful materials with little additional travel. It does not need to become your farm's central activity. Once the immediate crafting shortage is solved, return to the work you wanted the materials for.
