A gold-star small egg does not become gold Mayonnaise. For ordinary chicken eggs and milk, the size of the ingredient determines the usual processed quality. Sort by “Large” before using the stars as a processing rule.

## The everyday conversion table

| Ingredient | Result |
| --- | --- |
| Milk | Normal Cheese |
| Large Milk | Gold Cheese |
| Goat Milk | Normal Goat Cheese |
| Large Goat Milk | Gold Goat Cheese |
| Chicken Egg | Normal Mayonnaise |
| Large Chicken Egg | Gold Mayonnaise |

The [Cheese Press](https://stardewvalleywiki.com/Cheese_Press) and [Mayonnaise Machine](https://stardewvalleywiki.com/Mayonnaise_Machine) references document these conversions. The chicken-egg rule is not universal: Ostrich Eggs are an important exception, retaining input quality across their multiple jars. Keep unusual eggs separate until you know their result.

## Reserve ingredients before loading machines

A machine cannot return the original egg or milk for a bundle, delivery, or soup contribution. Make a small reservation area beside the collector, with only the items you already have a use for. Process the rest rather than keeping every quality variant indefinitely.

This is especially useful before the [Luau](/guides/luau-soup-ingredient-plan/). Choosing a contribution after all the good ingredients are already in machines creates an avoidable scramble. Read the item's full name when setting it aside; a small gold-star Milk and a Large Milk are different inventory entries.

For your first machines, process one of each common input and inspect the result. That gives you a reliable sorting habit without needing to remember every animal product in the game.

## Count collection, not just machine speed

A machine can finish while you are away, but it will not reload itself. If you only visit the animal area once each morning, plan around one dependable daily loading round. Extra theoretical cycles are useful only if your route actually includes another visit.

For example, four daily eggs and one machine create a queue if you only load once. You can add machines, return later, or sell part of the raw stock. Each is a reasonable choice; compare the extra walking with the resources needed for more equipment.

Keep a separate food stack if you use Cheese underground. Shipping all of it may increase today's balance while forcing you to buy replacement healing for tomorrow's trip. The [food and buff guide](/guides/cooking-and-food-buffs-guide/) covers that distinction.

Once the routine works, consider an [Auto-Grabber](/guides/auto-grabber-auto-petter-difference/). It makes collection easier, while your reservation and processing decisions still need a clear place in the morning route.

## A four-machine loading round

Four ordinary Chicken Eggs produce four normal Mayonnaise; four Large Chicken Eggs produce four gold Mayonnaise. At base prices, that is **760g versus 1,140g of finished goods**. Those totals are not the machine's added profit because the eggs themselves could also have been sold.

For a once-a-morning collection habit, four machines handle that four-egg round without a midday visit. With one machine, you need additional loading rounds or accept a backlog. Keep input size visible in the collector and reserve bundle eggs before choosing either schedule.
