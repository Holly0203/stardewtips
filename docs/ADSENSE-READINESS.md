# AdSense 改版与发布说明

本次保留 Astro、stardewtips.com、已有攻略 URL、发布商 ID 和 ads.txt；没有推送远程仓库或更改 AdSense 后台。

## 已落地

- 首页从 Canvas 星球改成无需 JavaScript 即可阅读的攻略入口：主题分类、推荐文章、季节规划。
- 新增 /start-here/ 新手阅读路线；攻略库提供浏览器本地搜索和无结果提示。
- 新增 /editorial-policy/ 和 /terms/；修订 About 和 Privacy，移除未经证实的全面实测声明，以及不存在的登录、评论、分析功能描述。
- 文章显示署名、适用版本、编辑说明与纠错入口；保留真实文章日期，不批量伪造更新日期。
- 修订三篇攻略中的已发现错误，包括社区中心位置与开启条件、杂草用途、春季采集物价值、虹鳟季节、春葱售价和不存在的肥料名称。
- 保留现有 AdSense 集成及账号验证元数据；404、联系、隐私等辅助页面不加载广告脚本。
- 去除外部字体请求，增加跳转正文、键盘焦点、减少动态效果、移动端布局和表格横向滚动。

## 发布前须实际确认

1. **内容复核**：本次没有逐条重新核验全部 21 篇攻略。站长应阅读全部现有文章，核查关键数值和游戏版本，特别是作物收益、NPC 礼物、解锁条件。数量和字数都不能代替内容价值，也不存在官方保证通过的文章数量门槛。
2. **广告同意管理**：现有 AdSense 脚本仍保留。若面向欧洲经济区、英国、瑞士投放个性化广告，在 AdSense 的“隐私权和消息”中配置、发布并测试 Google 认证 CMP。代码中的隐私说明和 opt-out 链接不能代替 CMP。未配置前不要把本版本视为已完成这项要求。
3. **联系方式**：确认 holly125@yeah.net 是运营者实际可用的联系邮箱；确认署名 Holly 和隐私政策准确反映实际运营及后台服务。
4. **图片权利**：现有游戏物品图标仍保留。注明权利归属不等于获得商业授权；运营者需要确认使用依据，必要时替换为有商业许可的素材。
5. **线上复验**：部署后检查真实域名 HTTPS、重定向、移动设备显示、robots.txt、sitemap-index.xml、ads.txt，以及 Search Console 抓取情况。通过 AdSense 后台确认审核状态，勿仅凭页面存在脚本判断通过。
6. **发布方式**：当前仓库使用 GitHub → Cloudflare Pages。按既有流程提交并推送后才会影响线上；本次仅修改本地，不自动提交原有未提交文件。
